# AOTY Tampermonkey Scripts

Userscripts for [Album of the Year](https://www.albumoftheyear.org/).

## Scripts

| Script | Purpose | Install |
|--------|---------|---------|
| **Score Hider** | Toggle visibility of all scores and ratings across AOTY, with persistent state | [Install](https://raw.githubusercontent.com/KazeTachinuu/aoty-tampermonkey/master/aoty-score-hider.user.js) |
| **Personal Score** | Display your own ratings on list pages without visiting each album | [Install](https://raw.githubusercontent.com/KazeTachinuu/aoty-tampermonkey/master/aoty-personal-score.user.js) |
| **Random Album Picker** | Pick a random album from any user's rated albums | [Install](https://raw.githubusercontent.com/KazeTachinuu/aoty-tampermonkey/master/aoty-random-album.user.js) |

## Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Click an install link above; Tampermonkey will prompt to install the script.

Scripts auto-update when new versions are pushed to this repo. Version numbers live in each script's userscript header.
